# z2roN_Merge (엑셀 병합) v1.0.0
같은 열 구성의 엑셀(.xls/.xlsx/.csv, 첫 시트)을 올릴 때마다 SQLite 누적 파일에 덧붙이고 바로 보여주는 Windows 프로그램 (C# WinForms, .NET 8).
- 정렬(다중), 찾기, 업로드 미리보기/되돌리기, 업로드 내역 삭제, 중복 건너뛰기(선택), xlsx/csv 내보내기(104만 행 초과 시 분할)
- 빌드: .github/workflows/build.yml (GitHub Actions, 단일 exe)

## v1.1.0
- 줄 삭제: 행 번호로 줄 선택(Ctrl/Shift 다중) → Del / [선택 행 삭제], 현재 화면의 모든 행 삭제, 삭제 취소(Ctrl+Z, 최근 5번 보관)
- 편집 > 현재 정렬 순서를 데이터에 확정(저장)

## v1.2.0
- 편집 > 열 기준 중복 값 삭제: 체크한 열 값이 같은 행 중 한 줄만 남김 (첫/마지막 선택, 빈 값 제외, 공백·대소문자 무시 옵션, 삭제 취소 가능)

## v1.3.0
- 편집 > 열 기준 중복 찾기/삭제 > [중복 행 보기]: 선택한 열 값이 같은 행만 모아서 표시 → 열 제목으로 정렬하고 원하는 줄만 선택해 삭제(Del). 삭제 후 중복이 풀린 행은 자동으로 목록에서 빠지며 Ctrl+Z 로 취소 가능
